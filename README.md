# softsrv starter repo

The purpose of this repo is to provide a standard artchitecture template, mainly for LLM use, to get a fast and consistent start on any application development.

# setup

- copy architecture.md into your project, or put it somewhere where your agent can access it.
- make sure to use some kind of initial prompt or agent. For example: "You are a senior go engineer. Create an application according to the specification in architecture.md"
